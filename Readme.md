Ascend — Landing Page Demo

A responsive landing page for a fictional software product, built as a guided portfolio project by Asokan Karish. A GetLayers design prompt was used as a starting point.

## Live demo

[View Ascend](https://asokankarish-ctrl.github.io/ascend-landing-page/)

## Features

- Dark theme with mint accents
- Responsive layouts for desktop and mobile
- Hero, features, illustrative dashboard, and contact sections
- Rotating 3D Earth using Google's model-viewer
- CSS fallback when the Earth model fails to load
- Scroll reveal effects with reduced-motion support
- Navigation between page sections and a personal portfolio link

## Technologies

HTML, CSS, JavaScript, and model-viewer.

## Project files

```text
ascend-landing-page/
  index.html
  style.css

  README.md
```

## Run locally

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.

An internet connection is needed to load the externally hosted model-viewer library and Earth model.

## About the demonstration

Ascend is a fictional product. The dashboard contains sample data. This project does not provide real accounts, payments, or backend services.
